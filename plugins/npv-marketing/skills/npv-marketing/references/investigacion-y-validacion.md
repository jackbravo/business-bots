# Investigación y validación antes de recomendar

Separar lo que dicen las fuentes de lo que permiten concluir. Antes de una recomendación estratégica o comercial, explorar estos cuatro frentes y profundizar según su posible efecto en la decisión. No convertirlos en cuatro informes obligatorios ni rellenar vacíos con generalidades.

| Frente | Qué comprobar |
| --- | --- |
| Ubicación actual | Movilidad, servicios, infraestructura, usos del suelo y cambios geográficos o riesgos relevantes para el producto. |
| Competencia en la zona | Alternativas del comprador comparables por ubicación, producto, superficie, entrega, precios y condiciones; oferta activa y mensajes. |
| Cambios del entorno | Empleo, ingresos, actividad local, crédito, tasas, inflación y otros cambios socioeconómicos, micro o macroeconómicos pertinentes. Explicar la relación con este producto, no solo enumerar indicadores. |
| Tendencias sociales del segmento | Hogares, retiro, trabajo, preferencias y hábitos de búsqueda o compra sustentados en estudios o señales contrastadas. Si el segmento aún no está validado, investigar posibilidades sin elegirlo por anticipado. |

## Consultar y contrastar

Obtener la ubicación del contexto disponible; si es ambigua, preguntarla antes de buscar comparables. Usar análisis previos cuando sigan vigentes y actualizar lo cambiante.

Preferir fuentes oficiales para entorno, fuentes directas para oferta y estudios para tendencias. Leer las fuentes relevantes, no solo fragmentos de búsqueda. Citar enlaces, fecha de publicación y periodo del dato cuando difieran. Explicar cómo cada hallazgo afecta o limita la decisión. Indicar si no se encontró evidencia pertinente para un frente.

La web del desarrollo sirve para revisar comunicación; no sustituye la investigación de competencia y entorno. Un anuncio externo no confirma inventario, precio o entrega vigentes. Contrastar esos datos con la fuente comercial del equipo. No sustituir datos internos de ventas o leads por cifras de otros proyectos.

## Validar antes de decidir

Mostrar hallazgos nuevos relevantes y separar su sustento del de las inferencias. Un hecho público puede tener sustento Medio y la propuesta derivada seguir siendo una hipótesis de sustento Bajo.

Contrastar con el equipo supuestos o contradicciones que cambien la recomendación y esperar la aclaración determinante. No pedir validación rutinaria de toda la investigación ni delegar al director la búsqueda de datos públicos.

No inferir escasez, desarrollo comprobado, ventaja frente a reventa o demanda por el mero hecho de ser la última torre. Comprobar disponibilidad, ejecución y relevancia para compradores antes de convertir esos argumentos en posicionamiento. No diagnosticar ventas lentas por una petición de lanzar una campaña.

Si no hay acceso web o el usuario pide no navegar, explicarlo y continuar con análisis provisional, preguntas y comprobaciones. No presentar una recomendación de mercado como contrastada ni fabricar fuentes. Mantener disponibles las mejoras puntuales de campaña y proceso comercial que sí tengan sustento.
